# AI Air Pencil

AI Air Pencil is a computer vision project that allows users to draw in the air using hand gestures.

## Features

- Real-time hand tracking using MediaPipe
- Index finger drawing
- Gesture recognition
- Coordinate smoothing
- Gesture stabilization
- Sudden movement rejection
- Multiple drawing colors
- Color selection toolbar
- Virtual eraser
- Binary drawing mask
- Canvas clearing

## Gestures



☝️ Draw 
✌️ Select Color 
🖐️ Erase 
✊ Idle 

## Controls

C - Clear canvas
Q - Quit
